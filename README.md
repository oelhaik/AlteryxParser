
Developed with python 3.9.13. This can be downloaded at this website:
https://www.python.org/downloads/release/python-3913/

In order to run this code you need a new GitHub token. Please follow this guide:
https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/creating-a-personal-access-token

After the token is generated, please replace the valuable this variable with the token in the code:

ACCESS_TOKEN
